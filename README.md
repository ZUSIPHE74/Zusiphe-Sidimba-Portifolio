# Zusiphe Sidimba — Interactive Portfolio

Welcome to the repository for my personal portfolio website. This is a high-performance, single-page application built to showcase my technical skills, software development projects, and industry-recognised certifications.

🔗 **Live Demo:** [https://zusiphe74.github.io/Zusiphe-Sidimba-Portifolio/](https://zusiphe74.github.io/Zusiphe-Sidimba-Portifolio/)

---

## 🚀 Key Features

- **Fluid Custom Cursor:** Interactive custom cursor ring that responds to pointer movement and hover events.
- **Dynamic Styling:** Modern typography, clean dark mode theme, subtle gradients, and glassmorphic UI elements.
- **Interactive Showcase:** Cards displaying key project details, metrics, tech stacks, live demos, and source code links.
- **Categorized Credentials:** Verification links for certifications in Cloud Infrastructure, AI, and Software Engineering.
- **Responsive Layout:** A mobile-friendly layout built with vanilla CSS Flexbox and Grid.

---

## 🛠️ Tech Stack

- **Structure:** Semantic HTML5
- **Styling:** Vanilla CSS3 (utilizing CSS Custom Properties/variables)
- **Logic:** Vanilla JavaScript ES6
- **Icons:** [Lucide Icons](https://lucide.dev/) (loaded via CDN)

## 💻 Local Setup & Run

To run this project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ZUSIPHE74/Zusiphe-Sidimba-Portifolio.git
   ```
2. **Navigate into the directory:**
   ```bash
   cd Zusiphe-Sidimba-Portifolio
   ```
3. **Open the project:**
   - Open `index.html` directly in your browser, or
   - Run a local server (e.g., Live Server extension in VS Code).
